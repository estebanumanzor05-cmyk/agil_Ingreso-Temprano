# ADR 03 · Sin-backend: los datos viven en el navegador

- Estado: Remplazado · 20 de octubre de 2026

- Contexto
Por el uso de Github pages, no existen un backend y los datos viven en el navegador

- Decisión
Al cambiar la estrategia de despliegue se usara una base de datos real, siempre siendo muck up

- Consecuencias
+ sincronizacion multi-dispositivo en tiempo real.
+ persistencia real del movimiento en los inventanrios
- retrasa el proyecto en torno a la entrega del sprint 3.
