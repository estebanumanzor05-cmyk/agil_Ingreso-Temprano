- Contexto
<!-- Qué situación obligó a decidir. Describe las restricciones reales del momento: tiempo disponible, conocimiento del equipo, tecnología que ya existía. Solo hechos, sin juicios. -->
El tiempo limitado para la realización del proyecto obligó a usar lenguajes que fueran manejables por todos los miembros del equipo. Fueron elegidos: HTML5, CSS3 y JavaScript.

- Decisión
<!-- Qué se decidió, en voz activa y en una o dos frases. -->
Se decidió usar HTML5, CSS3 y JavaScript porque son los lenguajes que más maneja el equipo y que nos permitirán terminar el proyecto en el poco tiempo que tenemos. 

- Consecuencias
<!-- Usa + para lo que se gana y - para lo que se pierde. Las negativas son obligatorias. -->
+ HTML permite organizar todo semánticamente.
+ CSS3 brinda responsive design.
- JavaScript requiere mantenimiento.
- JavaScript es menos seguro.
